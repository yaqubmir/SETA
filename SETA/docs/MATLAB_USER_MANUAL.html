SETA

Seizure Event Tagging and Annotation
Version 1.0 · MATLAB edition
Mohd Yaqub Mir · Lund University

Quick start

Extract the complete ZIP into a new folder. Open MATLAB, set Current Folder to the extracted SETA_Annotator_v1.0 folder, and run Runme. Keep all seven .m files together. The entry point creates a SETAAnnotatorApp instance named app.

Requires MATLAB with desktop UI support and Signal Processing Toolbox for candidate detection (sgolayfilt, designfilt, filtfilt, hilbert, findpeaks). mad may require Statistics and Machine Learning Toolbox depending on the installation. EDF loading requires edfread/edfinfo. No Python installation is required for this MATLAB edition. No minimum MATLAB release or cross-platform support is certified by this package.

1. Select and load data

Choose EDF / Session and Select Source to select the folder containing EDF files or grouped DAT files. Select the Session / File and click Load. Grouped DAT sessions take priority over EDFs when both are present. Alternatively choose Single DAT and select one file.

Grouped DAT naming: <session>_Ch1Biopot_1000Hz.dat through Ch8. The app reads eight little-endian float32 channels at 1000 Hz; the grouped loader divides samples by 1000. Single DAT is also float32, little-endian, 1000 Hz, but does NOT divide by 1000. Verify the input encoding and units; arbitrary DAT formats are not supported by these defaults.

EDF loading chooses EEG/Biopot/Ch-like channel names (or falls back to numeric channels), uses length consistency filtering, orders by length, keeps up to eight channels and pads missing channels with zeros. Verify channel identity before annotating. The loader attempts EDF timing and falls back to 2000 Hz; mixed-rate EDFs are not validated. Raw amplitudes retain the loader's units; the app does not enforce a common physical unit.

2. Inspect the EEG

Use All Channels or Single Channel and select the channel. Raw shows loaded samples; Preprocessed shows the display bandpass (default 5–80 Hz) and 50 Hz notch. This is a selector, not a simultaneous overlay. Changing the display filter does not change the detector's configured bands. The display filter can use an FFT fallback when toolbox functions are missing; this is not equivalent to the IIR path.

Use Prev, Next, Window (s), or the View Start / View End range controls. The time axis uses hh:mm:ss; saved annotation boundaries are seconds from recording start. Check raw and preprocessed views before assigning a label. The interface has a fixed large layout (1880 × 980), so a sufficiently large desktop is useful.

3. Generate candidates

Choose detection channels with the Detect checkboxes, adjust parameters if necessary, and click Run Detection. It processes the loaded recording for those channels, not only the visible window. Selecting a candidate opens its context and makes its features available to the annotation. The Max Dur control filters long candidates in the app.

The detector smooths using Savitzky–Golay, optionally trims recording edges, computes squared filtered band signals and robust median/MAD scores, finds peaks in the Hilbert envelope of the spike band, groups peaks into episodes, pads/merges episodes, and applies duration and spike-frequency thresholds. A weighted score combines spike density and broad/gamma/low band activity.

The legacy candidate_type values convulsive and behavior are assigned by an adaptive EEG score threshold. They are heuristic candidate tags, NOT video-confirmed behavior or a validated seizure diagnosis. The app contains no video player or automated video interpretation. Review any synchronized video separately and retain the alignment information in the study records.

4. Mark an interval

Select the correct channel, enter Ann Start (s) and Ann End (s), or use Pick Start / Pick End and click the trace. End must be later than start. Check the interval, then click Mark Seizure, Mark False, or Mark Normal.

Seizure records your positive review decision. False records a rejected candidate or artifact interval. Normal records a reviewer-selected normal/background interval. These are the literal stored labels; this version does not separately save HVSW, HPD, convulsive, or nonconvulsive as manual labels. Do not confuse candidate_type with the reviewer label.

All-channel annotations use channel 0. Select an individual channel for channel-specific training labels. Marking adds a row in memory; it is not an automatic save. Delete Selected removes the selected annotation from memory; Save Annotations is required to persist changes.

5. Save and reopen

Click Save Annotations. The app writes annotations.mat (variable annotations), annotations.xlsx, and annotations.csv into the selected source folder. Existing files with those names are overwritten. Keep a backup before editing an established dataset; do not open two app instances against the same annotation folder. The original save routine is not transactional across the three formats.

Selecting a source reloads existing annotations with priority MAT, then XLSX, then CSV. Editing only CSV while an older MAT remains will not update the labels loaded from MAT. Save frequently before switching source folders or closing the app. The original app refuses to save an empty annotation table; deleting every row will not clear existing disk files.

The saved table contains session_idx, session_name, channel, start_s, end_s, duration_s, label, candidate_idx, candidate_type, candidate_spike_count, candidate_spike_freq, candidate_peak_score, candidate_mean_score, candidate_mean_low, candidate_mean_gamma, candidate_mean_broad, created_at. Missing candidate values can be NaN. Preserve session and channel identity when preparing training data. Training itself is outside this package.

Default detection settings

Edge trim: 1 minute at each end when the recording is long enough; preserve original time: true. Savitzky–Golay order 1, frame 15 samples. Low band 3–12 Hz; gamma 20–50 Hz; broad 1–80 Hz; spike 15–80 Hz.

Spike threshold: median envelope + 4 × MAD; minimum peak spacing 80 ms; peak widths 15–500 ms. Maximum interspike interval 0.5 s; cluster padding 1 s; merge gap 2 s. Minimum episode duration 15 s; minimum spike frequency 2.5 Hz. Score smoothing 2 s; power smoothing 1 s. Score weights: spike density 1.2, broad 0.8, gamma 0.6, low 0.5. Adaptive candidate threshold uses the first 60 s of score with median + 5 × MAD.

These are source-code defaults, not validated universal biological cutoffs. The user guides and unrelated detectors in the supplied archive were excluded to avoid mixing algorithm versions. Keep a separate parameter record: annotation exports do not store a full detector configuration.

Troubleshooting and interpretation

No sessions: verify folder, .edf extension, or grouped DAT naming. Missing channel: grouped DAT mode requires all eight files. Unequal DAT channel lengths are truncated to the shortest. Filter errors: verify sampling rate, Nyquist limits, and sufficient signal length; use compatible nonempty recordings. No candidates: check channel selection and thresholds before changing criteria. Save error: ensure the source folder is writable and close Excel if it locks the XLSX file.

This is the original MATLAB annotator packaged with branding changes, not MIR NED and not the separate Batch 2 Python detector. The Python version of this specific app is not included or claimed equivalent. Runtime verification status is recorded in VALIDATION.txt. EEG event detection accuracy and inter-rater reliability require study-specific validation.
